## Brand notes

Icons use the Protego navy blue (#1A365D) as background color.
The official Protego shield logo should be placed on this background.
Contact the design team for official brand assets before launch.

## Replacing icons

1. Export all icon sizes from the brand design file
2. Name them exactly as listed above
3. Replace placeholder PNGs in this directory
4. Verify manifest.json references remain correct
